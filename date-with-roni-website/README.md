# דייט עם רוני

אתר אישי עם ג׳ימיקלוד — סוכן AI שאפשר לשאול אותו על רוני, לראות תמונות,
לבקש ממנו את הוואטסאפ שלו, או לקבוע דרכו דייט.

> **הפרונט מדבר עכשיו עם שרת ה-Ktor** שב-`../date-with-roni-server`, על פורט
> 8080. שרת ה-Node שב-`server/` נשאר כמו שהוא ומשמש כרפרנס — הוא כבר לא
> מחובר לדף.

## הרצה

```bash
npm install
npm start
```

- האתר: http://localhost:5173
- שרת הסוכן: http://localhost:3000

`npm start` מרים את שניהם יחד. אפשר גם בנפרד: `npm run web` ו-`npm run server`.

## מה כבר בנוי

**דף השיחה** — הזרימה המלאה:

1. היא לוחצת "להמשיך עם Google".
2. גוגל מחזירה ID token לדפדפן.
3. הדף שולח אותו ל-`POST /api/login`.
4. השרת מאמת את החתימה מול המפתחות של גוגל ומחזיר טוקן סשן משלנו.
5. הטוקן נשמר ב-localStorage, ומכאן כל הודעה נשלחת איתו.

אין טופס מייל, אין קישור לאשר ואין מסך המתנה. גוגל כבר מוודאת שהכתובת
שלה, ואין טעם לעשות את זה פעם שנייה.

**כניסה חוזרת** — טוקן שמור מדלג ישר לשיחה. אם הוא כבר לא תקף, הקריאה
הראשונה מחזירה 401 והדף חוזר למסך הכניסה עם הודעה.

**שלושה כלים לסוכן** — קישור וואטסאפ, שליחת בקשת דייט (אחרי שאסף שם וזמן),
והצגת תמונות. כלי התמונות קיים רק אם יש תמונות ב-`roni.js`, כדי שלא יבטיח
משהו שאין.

**תמונות בשיחה** — מוצגות בתוך הבועה, ולחיצה מגדילה למסך מלא. סגירה בלחיצה
או ב-Escape.

## חוזה ה-API

```
POST /api/login        { credential }        ה-ID token מגוגל
  -> 200 { token, email, name, tokensSpent }
  -> 400 חסר טוקן הכניסה
  -> 401 הכניסה לא אומתה
  -> 403 המייל בחשבון גוגל לא מאומת

POST /api/message      { token, text }        ← עוד לא קיים ב-Ktor
  -> 200 { text, images, tokensRemaining, active }
```

מבנה תמונה: `{ id, mime, data, alt }` כאשר `data` הוא base64 נקי, בלי
הקידומת. הלקוח מרכיב את ה-data URI בעצמו.

`401` או `404` מכל קריאה אומרים שהטוקן מת. הדף מוחק אותו וחוזר למסך הכניסה.

### תקציב טוקנים

לכל שיחה 40,000 טוקנים. אחרי כל קריאה למודל נגרע השימוש בפועל (קלט, פלט
וקאש), ו-`tokensRemaining` מוחזר בכל תשובה. באפס `active` הופך ל-false
והשיחה נסגרת. זה החסם מול מישהו שמוצא את נקודת הקצה ומנסה לשרוף תקציב.

## מה צריך למלא

### 1. `.env`

```bash
cp .env.example .env
```

| משתנה | בשביל מה |
|--------|-----------|
| `VITE_GOOGLE_CLIENT_ID` | כפתור הכניסה. בלעדיו הדף מציג שגיאה במקומו |

הקידומת `VITE_` היא מה שמאפשר ל-vite לחשוף את המשתנה לקוד בדפדפן. בלעדיה
הוא פשוט לא יגיע לשם.

ה-Client ID אינו סוד — הוא מופיע בקוד המקור של הדף ממילא. מה שמגן עליו הוא
רשימת ה-Authorized JavaScript origins אצל גוגל.

### 2. `server/roni.js`

הקובץ היחיד שקובע מה ג׳ימיקלוד יודע עליך. כל שדה שנשאר ריק פשוט לא נכנס
לפרומפט, והוא יגיד "אני לא יודע" במקום להמציא.

**תמונות**: הקבצים ב-`server/photos/`, ורשומים במערך `photos` עם כיתוב.
הכיתוב הוא מה שג׳ימיקלוד רואה, ולפיו הוא בוחר איזו תמונה מתאימה להראות —
אז שווה שיהיה תיאורי.

## פרטיות

תוכן ההתכתבות חי **רק בזיכרון של השרת**. הוא לא נכתב לדיסק, לא לבסיס
נתונים ולא ללוג, ונמחק כשהשיחה פגה או כשהתהליך נופל. הדבר היחיד שמגיע
לרוני הוא בקשת דייט שהיא ביקשה במפורש לשלוח — שם, מייל וזמן שנוח לה.

זה מה שמאפשר לכתוב בתחתית הדף "רוני לא מודע להתכתבות" ושזה יהיה נכון.
אם משנים את זה — צריך לשנות גם את הכיתוב.

## מבנה

```
index.html          כותרת הדף ונקודת הכניסה
src/main.js         שני מסכים: כניסה עם גוגל, ושיחה
src/style.css       העיצוב
server/index.js     נקודות הקצה והגבלת הקצב
server/agent.js     האינטגרציה עם Claude והכלים
server/roni.js      ← העובדות עליך והתמונות
server/photos/      ← קבצי התמונות
server/sessions.js  טוקנים, אקטיבציה ותקציב. בזיכרון בלבד
server/mailer.js    שליחת מיילים, עם נפילה למצב פיתוח
```

## מה עוד לא נבנה

דף הבית עצמו (תמונות, "עליי"), והעלאה לשרת.
